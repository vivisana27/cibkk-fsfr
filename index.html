⚠️ Dangerous Goods

ข้อมูลหน้านี้เรียบเรียงจากหน้า Dangerous Goods ของ China Airlines Cargo เพื่อใช้อ้างอิงเบื้องต้นเท่านั้น
กรุณาตรวจสอบกฎล่าสุดจาก IATA DGR และเว็บไซต์บริษัทก่อนรับงานจริงทุกครั้ง

📋 China Airlines Variation

  • CI-01: Passenger aircraft ไม่รับ Class 1 ถึง Class 8 ยกเว้น DG ที่ไม่ต้องใช้ DGD; รวมถึง UN3556, UN3557, UN3558 และ UN3091/UN3481/UN3552 Section I ตาม PI ที่เกี่ยวข้อง
  • CI-02: Excepted quantities ไม่รับ ยกเว้น radioactive materials, excepted package
  • CI-03: Consolidation ที่มีมากกว่า 1 HAWB ต้องให้ทุก HAWB เป็น DG ที่ต้องใช้ DGD
  • CI-04: Liquid DG ที่มี primary/subsidiary hazard Class 8 แบบ single packaging ต้อง overpack ด้วย rigid material ป้องกันด้านบนและด้านล่าง และต้อง stackable
  • CI-05: Oxygen Generator Chemical UN3356 ไม่รับขนส่ง
  • CI-06: Radioactive Material เข้า/ออก/ผ่าน Taiwan ต้องได้รับ approval จาก Nuclear Safety Commission ล่วงหน้า 7 วัน ยกเว้น excepted package
  • CI-07: DG ภายใต้ State exemptions หรือ State approval ไม่รับขนส่ง
  • CI-08: Class 7 ยกเว้น excepted package ต้องแยกจาก Class 1, 2, 3 และ 8
  • CI-09: ไม่รับ UN3090 PI968 Section IA/IB และ lithium battery บางกรณีเมื่อ overpacked หรือ packed with other DG classes
